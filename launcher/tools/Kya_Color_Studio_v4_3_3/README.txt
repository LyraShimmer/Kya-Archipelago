KYA COLOR STUDIO
================

An optional texture editor for Kya: Dark Lineage (PAL SLES-51473).

Launch START_KYA_COLOR_STUDIO.bat. This optional editor requires Python 3
and Pillow; the main Kya Archipelago Launcher EXE does not.

Select body parts, pick colors, use Brush/Eraser, or choose Randomize.
Apply writes a replacement texture to your chosen PCSX2 textures folder.
Restore Vanilla removes the active replacement. Existing user texture
replacements should be backed up before editing.

In PCSX2, enable Load Texture Replacements. Restart the game if an
already-loaded texture does not refresh.
